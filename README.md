## Introduction

This portfolio serves as a central place for my projects, experiments, and current learning. It presents my work in one interface and shows the tools, patterns, and frontend decisions I use across my applications.

The goal is to keep the presentation simple, technical, and easy to navigate, while making it clear what I build and what I am studying.

## Technical Overview

The portfolio is built with React and styled with Tailwind CSS. It uses EmailJS to handle contact form submissions without requiring a separate backend service for the site itself.

The application is deployed on Vercel and structured as a frontend-focused personal website. It is designed to highlight projects, development experience, and contact channels in a direct format.
